# Web-first: o navegador é o único cliente

O plano original era um app mobile (Expo) para registro rápido de plantões. Decidimos que o MVP é uma aplicação web acessada por navegador, com layout responsivo para celular. App nativo fica fora do roadmap até a experiência web doer de verdade.

**Consequências:** sem offline (o ADR-0005, sobre mobile online-only, é superado junto); uma única base de código de interface para manter.
