# Mobile nativo com Expo/React Native

**Contexto:** O app precisa de registro rápido de atividades no dia a dia (plantões dentro de hospitais) e um dashboard financeiro.

**Decisão:** React Native com Expo, compartilhando TypeScript com o backend via monorepo.

**Consequências:** + uma única linguagem e tipos compartilhados. − performance nativa inferior a Swift/Kotlin puro.
